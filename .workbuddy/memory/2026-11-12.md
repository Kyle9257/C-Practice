## VSCode C++ 调试配置修复（.vscode/ 已被 .gitignore 忽略，不进提交）

- 现象：F5 报 `launch: program 'D:\Git2\C-Practice\tier1_move\exercises\ex1_1_value_category.exe' does not exist`。
- 根因：`.vscode/` 只有 `tasks.json` 且用 `gcc.exe` 编 `.cpp`（gcc 驱动不链接 libstdc++，必然 undefined reference）；无 `launch.json`，F5 没有 `preLaunchTask` 就不会先构建，exe 从未生成。
- 修复：`tasks.json` 改用 `g++.exe`，两条 cppbuild 任务（默认 `C++: 构建当前文件 (C++20)`，备选 `(C++17)`），参数含 `-g -Wall -Wextra`；新建 `launch.json`（`cppdbg` + `MIMode: gdb` + `miDebuggerPath` 指向 Strawberry gdb + `console: integratedTerminal` + `preLaunchTask` 与 C++20 任务 label 完全一致）。
- 工具链：`C:\Strawberry\c\bin` 下 g++ 13.2.0、gdb 14.2，已在 PATH；扩展 `ms-vscode.cpptools` 1.35.6 已装。
- 未编译，按用户规则只做配置逻辑校验：两个 JSON 语法合法、label 与 preLaunchTask 一致、g++/gdb 路径存在。
- 遗留注意：pimpl 是多文件（widget.cpp + main.cpp），F5 单文件流程不适用，需命令行编译；tier4 走 CMake，不经此配置。
