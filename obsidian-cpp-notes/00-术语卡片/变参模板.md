# 变参模板

## 定义

接受任意数量、任意类型参数的模板，用参数包（parameter pack）`Args...` 表达，靠递归或折叠展开。

## 要点

- 参数包声明：`template <typename T, typename... Rest>`，`T` 是第一个，`Rest...` 是剩余。
- `sizeof...(Args)` 返回参数个数，是编译期常量。
- 展开方式两种：
  - **递归**：定义「递归基 + 递归步」，递归步里 `f(rest...)` 继续拆。
  - **折叠表达式**（C++17）：`(args + ...)` 一行搞定，替代递归。
- 典型应用：`make_unique`、`emplace_back`、`std::tuple` 的构造。

## 代码示例

```cpp
// 递归版
int sum() { return 0; }  // 递归基
template <typename T, typename... Rest>
int sum(T first, Rest... rest) { return first + sum(rest...); }

// 折叠版（C++17）
template <typename... Args>
auto sum2(Args... args) { return (args + ...); }
```
