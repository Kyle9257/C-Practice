# 完美转发

## 定义

函数模板把实参「原封不动」地转发给另一个函数，保留实参的值类别（左值/右值）。

## 要点

- 固定组合：`Args&&...` + `std::forward<Args>(args)...`。
- `std::forward<T>` 是条件转换：`T` 是 `int&` → `int&`，`T` 是 `int` → `int&&`。
- 与 `std::move` 的区别：move 无条件转右值，forward 保留原始类别。
- 典型场景：`make_unique`、`emplace_back` 等工厂/转发函数。
