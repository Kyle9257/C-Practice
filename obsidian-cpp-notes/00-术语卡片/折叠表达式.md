# 折叠表达式

## 定义

C++17 引入的语法糖，用二元运算符（`+`、`<<`、`,` 等）对参数包做递归展开，替代手写递归模板。

## 要点

- 四种形式（以 `+` 为例）：
  - 一元右折叠：`(args + ...)` = `a1 + (a2 + (a3 + ...))`
  - 一元左折叠：`(... + args)` = `((... + a1) + a2) + a3`
  - 二元右折叠：`(args + ... + init)`
  - 二元左折叠：`(init + ... + args)`
- 逗号折叠是打印/副作用常用套路：`((std::cout << args << " "), ...)`。
- 空包时一元折叠对 `&&` 为 true、`||` 为 false、`,` 为 void，其余运算符要求有初始值。

## 代码示例

```cpp
template <typename... Args>
auto sum(Args... args) { return (args + ...); }   // 右折叠

template <typename... Args>
void print_all(Args... args) {
    ((std::cout << args << " "), ...);            // 逗号折叠
}
```
