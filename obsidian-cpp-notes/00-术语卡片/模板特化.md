# 模板特化

## 定义

为模板的特定类型或类型模式提供专门实现，分为全特化和偏特化。

## 要点

- **全特化**：`template <> struct X<int> { ... }`，模板参数列表为空，锁定具体类型。
- **偏特化**：`template <typename T> struct X<T&> { ... }`，保留部分参数，只约束类型模式（引用、指针等）。
- **函数模板不能偏特化**，只能用重载替代。
- 多个偏特化若同时匹配会造成歧义（ambiguous），偏特化要设计成互不重叠。
- 编译期根据实参选择最匹配的特化，是 type-traits 的底层机制。

## 代码示例

```cpp
template <typename T> struct Kind { static const char* name() { return "值"; } };

// 偏特化：匹配引用
template <typename T> struct Kind<T&> { static const char* name() { return "引用"; } };

// 全特化
template <> struct Kind<int> { static const char* name() { return "int"; } };
```
