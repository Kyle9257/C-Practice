# 万能引用

## 定义

形如 `T&&` 且 `T` 由实参推导的引用参数，能同时接受左值和右值，故称万能引用（universal reference）。

## 要点

- 判定口诀：**`T&&` + `T` 被推导 = 万能引用**。
- 不是万能引用的情况：`const T&&`、`std::vector<T>&&`、显式指定 `T`（如 `f<int>(x)`）、类的 `T&&` 成员（无推导）。
- 推导结果：传左值 → `T = int&`，`T&&` 折叠成 `int&`；传右值 → `T = int`，`T&&` 是 `int&&`。
- 万能引用几乎总与 `std::forward<T>` 配对，用于完美转发。

## 代码示例

```cpp
template <typename T>
void f(T&& t) { /* T&& 是万能引用 */ }

int x = 0;
f(x);            // T = int&，形参折叠成 int&
f(5);            // T = int，形参是 int&&
```
