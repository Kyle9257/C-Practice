# 右值引用

## 定义

用 `T&&` 声明的引用，只能绑定到右值（临时对象、`std::move(x)` 的结果），用于实现移动语义。

## 要点

- `int&& r = 5;` 合法，`int&& r = x;`（x 是左值）非法。
- 关键反直觉点：**右值引用变量本身是左值**。`r` 有名字、可取地址，再传给重载函数时匹配 `int&` 而非 `int&&`。
- 想把它重新变回右值，唯一手段是 `std::move(r)`。
- 与 `const T&` 的区别：`const T&` 可绑左右值但只读；`T&&` 只绑右值但可改（可搬空）。
- 左值引用 `T&`、右值引用 `T&&`、万能引用 `T&&`（T 被推导时）三者要分清。

## 代码示例

```cpp
void f(int&)  { std::cout << "左值\n"; }
void f(int&&) { std::cout << "右值\n"; }

int x = 0;
int&& r = 5;
f(r);             // 左值  ← r 本身是左值
f(std::move(r));  // 右值
```
