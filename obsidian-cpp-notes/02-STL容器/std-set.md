# std::set

## 定义

有序、无重复元素的集合容器，底层是[[红黑树]]，自动排序。

## 要点

- 元素唯一，重复插入会被忽略。
- 插入/查找/删除均 O(log n)。
- 按键升序遍历，支持范围查找（[[lower_bound 与 upper_bound]]）。
- 迭代器/引用稳定，插入删除其他元素不影响已有迭代器。
- 要求元素支持 `<` 比较，或提供自定义比较器。

## 代码示例

```cpp
std::set<int> s;
s.insert(3);
s.insert(1);
s.insert(3);   // 重复，被忽略
// s = {1, 3}，自动有序
s.count(3);    // 1（存在与否）
s.erase(1);
```
