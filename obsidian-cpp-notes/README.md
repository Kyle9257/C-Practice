## 双链规范

- 首次提到术语时用 `[[术语名]]` 建链，例如 `[[std-map]]`、`[[红黑树]]`。
- 术语卡片里用「关联」区列反向链接，形成知识网。
- 卡片命名用英文标识符（如 `[[lower_bound]]`），正文标题用中文。

## 快速开始

1. 学到一个新概念 → 在 `00-术语卡片` 建卡。
2. 卡片里的关联概念继续 `[[]]` 展开。
3. 踩坑 → 记到 `04-踩坑记录`，回链相关术语。
